1. **Install Official Drivers:** Required USB Drivers.
Download and install the official Samsung USB Driver package on your PC. Reboot Windows to verify proper port assignment.

*Verification:* Connect the phone, open **Windows Device Manager**, and check that the device appears under **Ports (COM & LPT)** or **Universal Serial Bus controllers**.


2. **Connect Dongle and Launch Setup:** Hardware Dongle & Executable.
Insert your UMT / UMT Pro hardware dongle into a USB port. Right-click `UMTSams.exe` and select **Run as Administrator**.

*Verification:* The main UltimateSams dashboard will open and display valid dongle serial status in the diagnostic log.


3. **Connect Device and Execute Process:** Service Execution.
Select your target operation tab (**Flasher**, **Tools**, or **Service**). Place the Samsung device into the designated mode (Download Mode via Vol Down + Power + USB connection, or Test Mode via `*#0*#` on the emergency dialer) and click **Start** or **Reset FRP**.

*Verification:* Watch the output panel until the tool logs `Operation Finished: OK`.
